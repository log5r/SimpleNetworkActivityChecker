# Simple Network Activity Checker

Mac のインターネット接続を定期的に確認し、つながらないときに「どこで途切れているか」を示す macOS のメニューバー常駐アプリです。

接続経路を Mac に近い側から順に調べるので、原因が Wi‑Fi なのか、ルーターなのか、回線なのか、DNS なのかを切り分けられます。結果は記録され、稼働率や障害の履歴をあとから確認できます。

## 主な機能

- **段階的な診断**: 次の 6 段階を順に確認し、最初に失敗した箇所と対処方法を表示します。

  | 段階 | 確認内容 |
  | --- | --- |
  | ネットワーク接続 | Wi‑Fi やイーサネットで Mac がネットワークに接続されているか |
  | IPアドレス | ルーター（DHCP）から有効な IP アドレスを取得できているか |
  | ルーター | デフォルトゲートウェイまで通信が届くか |
  | インターネット | インターネット上のサーバーに IP アドレスで直接到達できるか |
  | DNS | ドメイン名を IP アドレスに変換できるか |
  | Webアクセス | Web サイトへ HTTPS でアクセスできるか（キャプティブポータルの検出を含む） |

- **メニューバー常駐**: ウインドウを閉じても監視を続け、メニューバーのアイコンで現在の状態を表示します。
- **自動チェック**: 設定した間隔（15 秒〜10 分、既定は 1 分）で確認します。接続できない間は 10 秒ごとに確認し、ネットワークの切り替え時とスリープ解除時にも確認します。
- **通知**: 接続が切れたときと復旧したときに通知します。
- **統計**: 稼働率、応答時間（平均・95 パーセンタイル・最大）、障害の一覧、原因別の集計を期間ごとに表示します。
- **エラーログ**: 接続できなくなった時点の診断結果を記録します。
- **書き出し**: チェック履歴・障害の一覧・エラーログを CSV / JSON / テキストで書き出せます。
- **ログイン時に起動**、記録の保存期間（7 日間〜無期限、既定は 90 日間）の設定に対応しています。

## 動作環境

- macOS 27.2 以降
- ビルドには macOS 27.2 SDK を含む Xcode が必要です

## ビルド方法

1. このリポジトリをクローンします。

   ```sh
   git clone https://github.com/log5r/SimpleNetworkActivityChecker.git
   ```

2. `SimpleNetworkActivityChecker.xcodeproj` を Xcode で開きます。
3. 必要に応じて「Signing & Capabilities」で自分の開発チームを選択します。
4. `SimpleNetworkActivityChecker` スキームを選択して実行（⌘R）します。

外部ライブラリには依存していません。

### コマンドラインからビルドして起動する

```sh
./start.sh
```

ビルド済みのアプリ（`build/DerivedData` 内）があればそれを起動し、なければ Debug 構成でビルドしてから起動します。ソースコードや署名設定を変更したときは、再ビルドしてください。

```sh
./start.sh rebuild
```

- `CONFIGURATION=Release ./start.sh rebuild` で Release 構成をビルドします。
- `NO_SIGN=1 ./start.sh rebuild` でコード署名なしでビルドします（ローカル開発用）。
- `Config/Signing.local.xcconfig` があれば、署名や Bundle ID の設定として自動的に読み込みます。このファイルは Git の管理対象外です。

### アプリケーションフォルダにインストールする

```sh
./install.sh
```

Release 構成でビルドし、`~/Applications` に配置します。アプリは起動しません。配置先のアプリが起動中なら、配置の直前に通常の方法で終了します。署名はローカル実行用のアドホック署名です。Xcode プロジェクトの署名設定を使う場合は `--project-signing` を、配置先を変える場合は `--destination` を指定します。その他のオプションは `./install.sh --help` で確認できます。

## 使い方

- 起動するとすぐに監視を始めます。メインウインドウのサイドバーから「状態」「統計」「エラーログ」を切り替えられます。
- 「今すぐチェック」（⌘R）で手動で確認できます。
- ウインドウを閉じてもアプリは終了しません。終了するにはメニューバーのアイコンから「終了」を選択します。
- 初回のチェック時にローカルネットワークへのアクセス許可を求められます。ルーターやローカルの DNS サーバーへの到達性を確認するために必要です。

## 通信先とプライバシー

診断のために次の宛先へ通信します。これ以外に診断結果や利用状況を外部へ送信することはありません。

- デフォルトゲートウェイ（ルーター）: ICMP ping、応答がない場合は TCP 80 / 443 / 53
- `1.1.1.1`（Cloudflare）、`8.8.8.8`（Google）: TCP 443 での到達確認
- システムに設定されている DNS サーバー: `www.apple.com` の名前解決
- `https://www.apple.com/library/test/success.html`、`https://www.google.com/generate_204`: HTTPS でのアクセス確認
- `captive.apple.com`: キャプティブポータルの検出

チェック履歴とエラーログは Mac 内（SwiftData）にのみ保存されます。アプリは App Sandbox 上で動作します。

## 構成

```
SimpleNetworkActivityChecker/
├── MyApp.swift          アプリのエントリポイント、メニューバー常駐の制御
├── ContentView.swift    メインウインドウ
├── Diagnostics/         各段階の診断とプローブ（ICMP / TCP / DNS / HTTP）
├── Monitor/             定期チェックのスケジューリングと設定
├── Statistics/          稼働率・障害・応答時間の集計
├── Storage/             SwiftData のモデル
├── Export/              CSV / JSON / テキストの書き出し
└── Views/               状態・統計・エラーログ・設定・メニューバーの各画面
```
